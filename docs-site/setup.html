Setup & configuration

One command brings up the whole system locally — Postgres, RabbitMQ, Redis and Typesense are provisioned as containers by .NET Aspire. You install nothing but the SDK and Docker.

Before you start

Prerequisites

  • .NET SDK 10.0.302+ (target net10.0).
  • The Aspire workload: dotnet workload install aspire.
  • Docker Desktop or Colima — any current version. Testcontainers uses it for the test suite too.
  • dotnet-ef 10.x for migrations.

No local Postgres, RabbitMQ, Redis or Typesense install is needed — Aspire runs them as containers.

First run

Set three secrets, then one command

Only three secrets cannot be faked; they are kept out of the repository as .NET user-secrets on the AppHost. Without an Anthropic key the LLM tier falls back to the Aspire-provisioned Ollama container.

Do clone, set secrets, run

# from the repo root
dotnet user-secrets --project src/Aspire/JobHunter.AppHost set "Anthropic:ApiKey"     "sk-ant-..."
dotnet user-secrets --project src/Aspire/JobHunter.AppHost set "Telegram:BotToken"    "1234:ABC..."
dotnet user-secrets --project src/Aspire/JobHunter.AppHost set "Telegram:OwnerChatId" "123456789"

# the one command that starts everything
dotnet run --project src/Aspire/JobHunter.AppHost

Check what comes up

Aspire dashboardhttps://localhost:17090 — live logs, traces, metrics
API + Scalar/OpenAPIhttps://localhost:7001/scalar
Typesensehttp://localhost:8108 (dev api-key dev-typesense-key)
pgweb · RabbitMQ · RedisInsightopened from the Aspire dashboard (RabbitMQ mgmt: guest/guest)

Migrations apply automatically on first start in Development.

Everyday commands

Build, test, migrate, drive a stage

dotnet build && dotnet test           # full hermetic suite, needs Docker
./coverage.sh                          # coverage report, same gate as CI (>90%)

dotnet ef migrations add F2_AddJobsAndAliases \
  --project src/JobHunter.Infrastructure \
  --startup-project src/JobHunter.Worker \
  --output-dir Persistence/Migrations

dotnet run --project src/JobHunter.Worker -- run-stage discovery --company stripe.com
dotnet run --project src/JobHunter.Worker -- run-once --dry-run   # full Run, no LLM, no delivery
dotnet run --project src/JobHunter.Worker -- seed --companies tools/seed/companies.yaml

Prefer no Aspire? compose.yaml brings up the backing services and you set ConnectionStrings__JobHunter and ConnectionStrings__Messaging by hand.

Configuration that matters

The knobs an operator actually turns

SettingMeaning
Run:CeilingUsdThe hard per-Run cost ceiling, snapshotted onto the Run at creation. Example live value: $2.00. Raising it is an Infisical change plus a worker restart.
ModelTier → modelCheap = claude-haiku-4-5; Deep = claude-sonnet-5 (upgrade path claude-opus-5). The tier→model map is config, not code.
Digest schedule07:00 ±3 min Europe/Kyiv, every day. Cron declared in Kyiv time, not UTC; a DST test asserts 07:00 stays 07:00. Assembly deadline 06:45.
Discovery:RequestsPerSecondPerHostPer-host rate budget, default ≤ 1 req/s, enforced by a Redis token bucket keyed {env}:jobhunter:ratelimit:{host}.
AllowlistsBot: OwnerAuthorizer drops any chat id not on the list. API: Keycloak realm jobhunter, scopes jobhunter:read / jobhunter:admin, default-deny.
Where config lives: local dev uses user-secrets + appsettings; deployed non-secret config is a Terraform-managed ConfigMap jobhunter-infra-config; secrets come from Infisical at pod startup (paths /app/connections, /app/auth, /app/services). Options validate at startup via .Validate().ValidateOnStart(), never at first use.

Запуск

Встановлення й конфігурація

Одна команда піднімає всю систему локально — Postgres, RabbitMQ, Redis і Typesense надаються як контейнери через .NET Aspire. Ви встановлюєте лише SDK і Docker.

Перед початком

Передумови

  • .NET SDK 10.0.302+ (ціль net10.0).
  • Робоче навантаження Aspire: dotnet workload install aspire.
  • Docker Desktop або Colima — будь-яка актуальна версія. Testcontainers також використовує його для тестів.
  • dotnet-ef 10.x для міграцій.

Локально встановлювати Postgres, RabbitMQ, Redis чи Typesense не треба — Aspire запускає їх як контейнери.

Перший запуск

Задайте три секрети, потім одна команда

Лише три секрети не можна підробити; вони тримаються поза репозиторієм як .NET user-secrets на AppHost. Без ключа Anthropic рівень LLM переходить на контейнер Ollama, наданий Aspire.

Do клон, секрети, запуск

# з кореня репозиторію
dotnet user-secrets --project src/Aspire/JobHunter.AppHost set "Anthropic:ApiKey"     "sk-ant-..."
dotnet user-secrets --project src/Aspire/JobHunter.AppHost set "Telegram:BotToken"    "1234:ABC..."
dotnet user-secrets --project src/Aspire/JobHunter.AppHost set "Telegram:OwnerChatId" "123456789"

# одна команда, що запускає все
dotnet run --project src/Aspire/JobHunter.AppHost

Check що піднімається

Панель Aspirehttps://localhost:17090 — живі логи, трейси, метрики
API + Scalar/OpenAPIhttps://localhost:7001/scalar
Typesensehttp://localhost:8108 (dev api-key dev-typesense-key)
pgweb · RabbitMQ · RedisInsightвідкриваються з панелі Aspire (RabbitMQ mgmt: guest/guest)

Міграції застосовуються автоматично при першому старті в Development.
