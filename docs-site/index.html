The 07:00 digest

One good morning message, engineered end to end

JobHunter discovers engineering jobs from ATS boards, ranks them with Claude against one CV, and delivers a single Telegram digest at 07:00 Europe/Kyiv. It serves exactly one person — and it is, deliberately, a portfolio artifact: the architecture, the tests and these docs are part of the deliverable.

The shape of a day

Discovery runs all day; the digest is assembled at dawn

Discovery polls each company's ATS board every six hours and stores raw postings immutably. Overnight, one Run enriches the day's new jobs, matches them against the CV, ranks them, researches the top companies, assembles a digest and delivers it at 07:00. The Owner taps Open, Ignore, Save or Applied — and those taps become the preference weights that reorder tomorrow.

Як виглядає день

Discovery працює цілий день; дайджест збирається на світанку

Discovery опитує ATS-дошку кожної компанії кожні шість годин і незмінно зберігає сирі оголошення. Уночі один Run збагачує нові вакансії дня, зіставляє їх із резюме, ранжує, досліджує топ-компанії, збирає дайджест і доставляє його о 07:00. Власник тисне Open, Ignore, Save або Applied — і ці дотики стають ваговими коефіцієнтами вподобань, що переставляють завтрашній список.
